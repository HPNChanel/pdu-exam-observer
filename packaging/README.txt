PDU Exam Observer M1 trial bundle

This unsigned Windows one-folder trial is local-only and intended for a
deterministic synthetic demo plus M1 research-governance preparation. It does
not include Python or Node prerequisites at runtime. M1 adds SQLite metadata,
retention and consent receipts, restart recovery, and participant-wide
withdrawal. It cannot record a research participant.

The default runtime is M0. Configure M1 once from a terminal before launch:

  PDUExamObserver.exe configure --root D:\PDU-Research-Data

Then set PDU_RUNTIME_MODE=m1 and PDU_REVIEWER_PIN in the launch process.
Encryption and ACL default to UNKNOWN and remain blocking readiness gates.
Do not mark either VERIFIED without actual operator evidence.

Camera capture, MediaPipe, FFmpeg, model inference, clean-machine portability,
institutional approval, real participant collection, and physical two-monitor
behavior remain UNVERIFIED.

Runtime data, logs, exports, identity mappings, imported models, and real media
must live outside this application directory.
